HSI Hypergraph Network

Hyperspectral Image Classification Using Multi-Feature Fusion Residual Hypergraph Convolution Network

Deep learning has significantly advanced hyperspectral image (HSI) classification by automating feature extraction, overcoming traditional manual methods. While pixel-level approaches (e.g., 1D-CNNs, RNNs) process spectral data, they neglect spatial context. Patch-level methods (e.g., 3D-CNNs, capsule networks) improve accuracy by incorporating spatial-spectral cubes but struggle with long-range dependencies and nonlocal information loss. Graph convolutional networks (GCNs) have emerged as an alternative, modeling pixel relationships via graphs, yet they rely on fixed adjacency matrices and fail to capture higher-order structures.

To address these limitations, we propose the Multimodal-Feature Residual Hypergraph Convolutional Network (MF-RHCN) (Zhu et al., 2023)., leveraging hypergraph neural networks (HGNNs) to model complex, higher-order relationships in HSI data. Unlike conventional graphs, hypergraphs use hyperedges to connect multiple nodes, enabling richer representation of land-cover correlations. Our key contributions include:

  1. Multimodal feature fusion via hypergraph-based incidence matrix concatenation, effectively combining spectral and spatial information.
  2. A multiscale convolutional module to extract fine-grained local features, compensating for hypergraph limitations in capturing detailed structures.
  3. Residual learning and identity mappings to prevent over-smoothing while preserving high-order relationships.
  4. Computational optimizations, including hypergraph Laplacian matrices and Chebyshev polynomials, improving efficiency for large-scale HSI datasets.

By integrating global hypergraph modeling with local multiscale feature extraction, MF-RHCN achieves state-of-the-art classification accuracy. This end-to-end framework offers a robust solution for HSI analysis, balancing spectral-spatial detail with computational efficiency, with broad applications in remote sensing and environmental monitoring.
